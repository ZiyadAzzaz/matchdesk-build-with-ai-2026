    A SMALL, HONEST WORKSPACE

    You stay in control.

    Supported currencies: USD, EUR, GBP, EGP, CAD and AUD. Matching uses exact customer scope and currency. No fuzzy identities, accounting advice or paid AI service.

    The browser sends files to this app’s server. When run locally, that is this computer. Files are not sent to a bank or AI API. Session data expires after 90 minutes without API activity and is lost on server restart. This prototype is intended for local use, not a public financial service.
